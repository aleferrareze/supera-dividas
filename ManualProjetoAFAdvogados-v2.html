1. Visão Geral do Projeto

O que é: Sistema web de prova objetiva online para seleção de estagiários do escritório AF Advogados. Os candidatos acessam pelo link, preenchem um formulário, realizam 20 questões de múltipla escolha com proteção anti-cola e, ao finalizar, o resultado é exibido imediatamente.

Tecnologias utilizadas

TecnologiaFunçãoStatus
React + Vite + TypeScriptInterface do site (front-end)ATIVO
Tailwind CSSEstilização visualATIVO
Vercel NOVOHospedagem principal do site — substitui HostingerATIVO
GitHubCódigo-fonte e deploy automáticoATIVO
HostingerRegistra o domínio advocaciaaf.com.br — não serve mais o appSÓ DNS
SupabaseBanco de dados — configurado mas não integrado na versão atualINATIVO

⚠️ Sobre o Supabase: O Supabase foi configurado em uma sessão anterior mas o código atualmente em produção usa localStorage para salvar resultados. Isso significa que cada resultado fica salvo apenas no dispositivo/navegador do candidato. Para centralizar os resultados em um banco de dados, a integração com Supabase precisa ser reativada (ver Seção 3).

Funcionamento resumido

1
Candidato acessa estagio.advocaciaaf.com.br e preenche nome, e-mail, WhatsApp, curso, semestre e cidade
2
Sistema bloqueia a tela em modo fullscreen com anti-cola (sem copiar, colar, trocar aba ou sair)
3
Candidato responde 20 questões (tempo mínimo: 10 min / máximo: 90 min)
4
Ao finalizar, resultado é salvo no localStorage do navegador e exibido na tela
5
Administrador acessa o painel (/?admin), vê resultados do dispositivo atual e exporta CSV

8. Resolução de Problemas

Site não abre em estagio.advocaciaaf.com.br

Causa mais comum: DNS ainda propagando (pode levar até 24h após mudança).
Teste imediato: Acesse prova-estagiario-af.vercel.app — se abrir, o problema é só o DNS.
Se o DNS estiver errado: hPanel Hostinger → Zona DNS → confirmar que existe CNAME estagio → cname.vercel-dns.com.

Painel admin não mostra resultados

Causa (versão atual): O painel admin lê resultados do localStorage do navegador. Se você está acessando o admin de um dispositivo diferente do candidato, não verá os resultados.
Solução imediata: Acesse o admin no mesmo dispositivo/navegador onde a prova foi feita.
Solução definitiva: Reativar integração com Supabase (ver Seção 3).

Deploy no Vercel com erro

Como verificar: Acesse vercel.com/ferrarezedias-6722s-projects/prova-estagiario-af → veja o último deployment.
Se o build falhou: Clique no deployment com erro → veja os logs → identifique o arquivo com problema.
Solução: Corrija o código no GitHub e faça um novo commit — o Vercel tentará o build novamente.

Candidato não consegue finalizar a prova

Motivo mais comum: O tempo mínimo de 10 minutos ainda não passou. O botão "Finalizar" só aparece após 10 minutos. Isso é proposital.

Candidato diz que a prova está bloqueada

Causa: O candidato saiu da tela 2 vezes (troca de aba, minimizar ou sair do fullscreen).
Solução: O candidato deve acessar de outro navegador ou dispositivo. O bloqueio é por localStorage — cada navegador é independente.

Como alterar questões ou gabarito

1
Acesse github.com/aleferrareze/prova-estagiario-af
2
Clique em src/data/questions.ts
3
Clique no ícone de lápis (editar)
4
Altere o texto das questões ou o campo correctAnswer
5
Clique em Commit changes — o Vercel atualiza o site em ~2 minutos

Como exportar resultados

Acesse o painel admin (estagio.advocaciaaf.com.br/?admin), faça login com a senha e clique em Exportar CSV. O arquivo abre diretamente no Excel.
